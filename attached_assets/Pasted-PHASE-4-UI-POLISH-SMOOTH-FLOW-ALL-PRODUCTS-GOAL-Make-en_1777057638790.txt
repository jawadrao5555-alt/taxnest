PHASE 4 — UI POLISH + SMOOTH FLOW (ALL PRODUCTS)

GOAL:
Make entire SaaS feel FAST, SMOOTH, and PREMIUM (no lag, no flicker, no dead focus).

--------------------------------------------------

A) GLOBAL PERFORMANCE

1. Debounce everywhere:
- search inputs (50–80ms)
- customer search
- product filter

2. Remove unnecessary watchers:
- no deep watchers unless required
- recalc only when needed

3. Use requestAnimationFrame for heavy UI updates (cart, totals)

--------------------------------------------------

B) INPUT EXPERIENCE (CRITICAL)

1. ALL inputs:
- auto-select on focus
- no cursor jump
- no lag on typing

2. Prevent blocking:
- no localStorage writes per keystroke (already fixed in POS — verify globally)

--------------------------------------------------

C) LOADING STATES

Add visible feedback:

- customer search → spinner inside input
- product search → skeleton or "Searching..."
- payment submit → button shows "Processing..."

NO silent waits.

--------------------------------------------------

D) FOCUS FLOW (ZERO DEAD ZONES)

Define strict chain:

POS:
Phone → Product search → Cart → Payment → Back to Phone

FBR POS:
Item name → HS → Qty/Value → Next row → Payment

DI:
Customer → Items → Submit → Reset

After EVERY action:
→ focus must land somewhere meaningful
