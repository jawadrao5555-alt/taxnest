C) FBR POS — VALUE MODE (FBR-COMPLIANT)
════════════════════════════════════

Add VALUE MODE per row (toggle [QTY | VALUE], default QTY).

1) Internal base unit:
- KG → grams (1000)
- LTR → ml (1000)

2) VALUE MODE behavior:
- User edits VALUE (Rs)
- Compute:
  grams = round((value / unit_price) * 1000)
  quantity = grams / 1000

3) Reverse sync:
- If quantity changes:
  value = quantity * unit_price

4) FBR payload (unchanged contract):
- Send quantity in KG/LTR (decimal)
- Ensure:
  valueSalesExcludingST == quantity * unit_price

5) Precision:
- quantity rounded to max 3 decimals
- Final authority:
  value = quantity * price (recomputed before submit)

6) Guardrails:
- Disable VALUE MODE if unit_price <= 0
- Disable for non-measurable items (PCS/services)
