SECTION 1 — EXECUTIVE VERDICT
-----------------------------

Architecture verdict: TaxNest is a single Laravel 11 monolith (routes/web.php
only; no routes/api.php) serving FOUR product types (di, pos, fbrpos, erps)
behind SEVEN auth guards, with explicit-company_id discipline for POS/FBR and
a CompanyScope global scope for DI/Health models. It is understood deeply
enough to investigate, diagnose, design and implement a future issue WITHOUT
another broad discovery, with the explicit UNKNOWNs listed in Section 25 and
map 14.

Security verdict: TWO CRITICAL code-level findings, one of which is NEW in
this audit and CHAINS with the PR #26 finding:
  C1. GET /setup-migrate-xK9mP2 and GET /setup-seed-xK9mP2 — unauthenticated
      Artisan migrate/db:seed --force (PR #26 finding, INDEPENDENTLY CONFIRMED,
      upgraded from "CONFIRMED RISK in code" to CONFIRMED VULNERABILITY in
      code; production reachability UNKNOWN).
  C2. GET /demo-login/{role} — unauthenticated GET that logs the visitor in as
      a hard-coded email (admin@test.com for role super_admin) if that users
      row exists. NEW FINDING. db:seed via C1 CREATES exactly that row with
      users.role=super_admin. Chain C1→C2 yields a web-guard User with
      role=super_admin: RoleMiddleware bypass, CompanyScope bypass,
      RateLimitByCompany bypass, DI cross-company invoice reads, platform tax
      rule mutation. No APP_ENV guard on either route.

PR #26 challenge outcome: PR #26 was materially correct on every point I could
verify (four products, whole-rupee/2dp split, reporting-OFF NULL, fiscal_device
no server submit, orphan jobs, dual isSuperAdmin, 30s heartbeat, branch gaps),
but it UNDER-REPORTED severity in three places (demo-login chain not found;
plaintext agent API keys; ForceHttps listed as hardening while unwired) and
carried several stale naming details (claimed_at/printed_at columns that do not
exist; users.active_branch_id column that does not exist — it is a session
key). Details in Section 24.

Decision: READY FOR TARGETED ENGINEERING — with C1/C2 requiring an immediate,
separate, owner-approved remediation PR before any other work.
