# Customer announcement language

Write each update for a shop owner using the software. Keep the customer's selected language and use short, familiar sentences.

- Say what changed, where the option is, and what the user needs to do.
- Use the exact visible button/page name when giving an instruction.
- Prefer one change per point. Explain a necessary condition such as internet access in a separate sentence.
- Keep SHA, receipt keys, metadata, callbacks, packaging, allocation, provenance and workflow details in the PR or QA notes.
- State real limits plainly. Do not promise recovery of already missing bills, a completed deployment, or a printing fix without evidence.
- Preserve the approved audience, business categories and saved read state. Clearer wording must not widen who receives an update.

Example: “Deal allocation aur historical snapshot reconcile hote hain” becomes “Deal mein tax wale aur tax se chhoot wale items ka hisaab alag hota hai. Return karte waqt asal bill ka tax aur cost li jati hai.”
