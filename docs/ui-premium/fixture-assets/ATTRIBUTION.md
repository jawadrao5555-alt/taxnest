# Premium UI fixture-photo attribution

These eight compact JPGs are local, presentation-only fixture assets for the
synthetic PRA restaurant catalogue. They were selected with the image-search
skill and downloaded from Unsplash image URLs using the `w=640`, `h=440`,
`q=60` transformation. Each file is under 100 KB. They are copied only into
the disposable `rc-premium` image directory by
`scripts/premium-ui-fixture-extension.php`.

Unsplash images are made available under the [Unsplash
License](https://unsplash.com/license). The source image URLs below are
retained so the fixture can be audited or replaced without treating a photo
as application data.
