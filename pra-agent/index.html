FBR IMS Fiscal Service (Fiscal Device Mode)

Checking…
FBR bills need FBR's own IMS service running on this PC. Click Install FBR IMS — the agent downloads it from FBR's official server and launches the installer. After installing, open the FBR IMS app once and activate:
1️⃣ Enter your POS Registration No   2️⃣ Enter the Access Code from IRIS (Point of Sale Registration page)   3️⃣ Select Production
Then press Re-check — when the badge turns green, queued bills sync automatically.
